---
id: T-0007
title: BC-11 - self-service privacy export and a rectification queue
milestone: M-0001
priority: '1'
status: ready
rev: 1
objective: Let a student download a machine-readable copy of their own data and file a correction request that staff must decide and, when accepted, apply with an audit trail.
outcome: A data subject can exercise access and rectification without emailing an officer, nothing is exported that is not theirs, and every correction has a requester, a decision, a decider and a reason.
verification_profile: code
integration_target: develop
deployment_impact: code
deployment_verification: Local gates and CI only; the one automatic deployment is the integrator push to develop.
dependencies: []
ownership:
  - server/api/privacy/**
  - server/utils/privacy.ts
  - app/pages/privacy/**
  - app/pages/account/**
  - prisma/migrations/*_privacy_requests/**
  - prisma/schema.prisma
  - tests/unit/privacy.test.ts
  - scripts/e2e/privacy.e2e.mts
  - scripts/e2e/run.mts
out_of_scope:
  - Deleting records; this is export and correction, not erasure
  - Any change to the frozen public site
interfaces:
  - GET /api/privacy/export returns the caller own data as JSON
  - POST /api/privacy/requests files a rectification request
  - staff decision endpoint with accept or reject and a reason
deliverables:
  - additive migration for privacy_requests with status, decidedBy, decidedAt, reason
  - pure rules for what an export may contain and which fields are correctable
  - export excludes other people and internal notes
  - staff queue UI plus the student request form
  - live suite registered in the runner
acceptance:
  - 'AC1 [test]: an export contains the caller own attendance, fines and profile, and nothing belonging to another student'
  - 'AC2 [test]: a request needs a field and a proposed value, and cannot target a non-correctable field'
  - 'AC3 [test]: accepting a request applies the change and writes one audit row naming requester, decider and reason'
  - 'AC4 [cmd]: npx eslint . && npm run typecheck && npm run typecheck:legacy && npx vitest run'
constraints_security:
  - The export is served only to the authenticated owner and is never cached publicly.
  - No other student identifiers, amounts or notes appear in an export.
constraints_compatibility:
  - Additive migration only; schema.prisma and scripts/e2e/run.mts are shared and integrated serially.
database_migration: additive
escalation:
  - If a correctable field is derived rather than stored, list it for a decision instead of making the export claim a value it cannot change.
